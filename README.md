# Laravel Blog Website

A full-stack blog website built with **Laravel, PHP, MySQL, jQuery, and AJAX**.

### Features

* 🔐 Authentication & user management
* 📝 Blog CRUD
* 📂 Category & subcategory management
* 🔎 Blog search
* ⚡ AJAX dynamic content
* 👤 User profile
* 📊 Admin dashboard

### Tech Stack

**Laravel • PHP • MySQL • jQuery • AJAX • Bootstrap**

## Installation

```bash
git clone https://github.com/jahir002201/blogs.git
cd blogs
composer install
npm install
cp .env.example .env
php artisan key:generate
php artisan serve
```

Configure your MySQL database in `.env`, then import `blog.sql` if required.
